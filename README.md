# The portfolio page

One static `index.html`, generated by `build.py`. No framework, no build pipeline.

Live: https://moheetsubudhi.com/ (custom domain via `CNAME`; the github.io address redirects here)
Repo: https://github.com/moheetsubudhi-isb/moheet-portfolio (source and the generated page)

## Rebuild and deploy

In the repo, everything sits at the root:

```bash
git clone https://github.com/moheetsubudhi-isb/moheet-portfolio && cd moheet-portfolio
python3 build.py        # reads ./giveaways, rewrites ./index.html
git add -A && git commit -m "…" && git push
```

GitHub Pages publishes about a minute after the push. Python 3 only, no packages.

`build.py` looks for `giveaways/` beside itself and, failing that, one folder up, so the
same file runs from the repo or from the original working folder (`site/` with `giveaways/`
next to it). If you edit in the working folder, copy `build.py`, `art-light.json`,
`icons.json`, `README.md`, the generated `index.html` and `giveaways/01`–`05` into the repo,
or the repo falls behind. It did once.

## What goes in

| Input | What it supplies |
|---|---|
| `giveaways/01`–`04` | Every copyable block. `content()` extracts them between `===== COPY FROM HERE =====` markers or by fenced block, so the page and the files cannot drift. |
| `art-light.json` | The deck's diagrams, recoloured for paper, accents as `var(--accent)` and `var(--accent-2)`. Produced by `extract-art.js` from the deck. |
| `icons.json` | 22 Phosphor duotone icons, inlined, so the page needs no icon CDN. |

## The tree

`views()` returns the tree. Every node is `{slug, label, icon, title, lede}` plus either a
`body` (a page) or `children` (a folder). A folder renders as its own poster. Paths are
slug chains: `build/loop`, `projects/ownr`.

`build()` takes the tree and:
- renders every tile once, tagged `data-parent`; the poster shows the set for the current folder
- renders a pane for every leaf
- writes `SLUGS`, `TITLES`, `PARENTS`, `FOLDERS` and `PICS` into the script

To add a project: one `dict(...)` in the `children` list of `projects`. The tile, icon,
route, search entry and breadcrumb follow. Pick an `icon` that exists in `icons.json`.

Current root: **How to Build with AI** (seven parts, Setup Interview, soul files, loop
checklist, tool registry, the skills kit, Second Brain, run it on your laptop) · **Business Analytics
Skills** (one leaf) · **My projects** (Ownr) · **Moheet CV** (one leaf, a stamp tile).

The CV lives in `CV` in `build.py`, written with `cv_rec()` and `cv_field()`. Edit the
facts there and rebuild. The download is `cv/moheet-subudhi-cv.pdf`; replace that file to
update it. A node with `stamp=dict(img=..., text=...)` shows a postage stamp in place of
its icon; everything else about the tile stays the same.

## Rules the page keeps

- **One poster at every level.** Same heading, search, scatter, drag and top bar whether the
  folder holds one tile or ten. Never branch on the count; the scatter has no minimum.
- **One tile size.** Tiles do not scale with how few there are.
- **One top bar** for folders and pages: back pill plus a trail showing only where you are.
  The pill already names the parent, so the trail never repeats it.
- **One search**, a ranked results panel over every node. In an opened page the same element
  moves into the top bar. Anchored under the box so nothing reflows while typing.
- **The ruling and vignette are fixed**; content scrolls over them.
- **Reduced motion is respected**, and every animation has a path to its final state if a
  timer or frame is dropped.

## Gotchas this codebase has already hit

- The page is an f-string, so every `{` and `}` in the embedded JS and CSS must be doubled.
  Author normally and escape, or you get `f-string: expecting a valid expression`.
- `display` on an element beats the `hidden` attribute. There is one global
  `[hidden]{display:none!important}` for this reason; without it every other folder's tiles
  stayed in the layout as zero-width flex items.
- Hidden panes measure as zero. Run layout when a poster becomes visible, never at load.
- Scope `layoutScatter` to `#hub .obj` that are not hidden, or it picks up other folders.
- `stroke-dashoffset` animations are main-thread and stall in a tab that is not painting.
  Use `transform` or `opacity` for anything that must finish.
- `requestAnimationFrame` can be throttled in previews. Use CSS classes and timers.
- `history.pushState` throws on `file://` and in some sandboxes; `setUrl` falls back to the hash.
- A CSS animation only plays on a new element, so text that must re-animate is rewritten
  as fresh spans.
- iOS Safari ignores `background-attachment:fixed`; the ruling uses a `position:fixed`
  pseudo-element.
- GitHub redirects a renamed repository but not the Pages site it publishes. The old
  `build-with-ai` repo is kept as a one-page redirect for that reason.

## Verifying a change

Check every page, not the one you touched, at 1440×880 and 375×812: no horizontal overflow,
no page scroll on a poster, no overlapping tiles, every tile clickable, the heading centred
and clear of the top bar, back climbing exactly one level, search reaching every node.
