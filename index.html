(01)

The generator

One prompt. It interviews you for five minutes, then writes four files for your actual job.

It asks what you do, what you redo every week and resent, how you do it now, and what keeps going wrong. Then it writes: how it should behave, how it should work, what it can reach, and how you do that one task.

Paste it as the first message in any chat. Claude, ChatGPT, Gemini, Copilot. It works in a terminal agent too, and on a phone.

The generatorabout 5 minutes


The third question is the one people rush. Walk it through how you actually
do the thing, fiddly parts included. The skill it writes is only as good as that answer.

(03)
Make it finish instead of wander
Four lines above any task: the goal, the check, the stop, the limit.


The check is the one people skip and the one that matters. "I will review it
carefully" is not a check. "Both totals match the source file" is, because it can fail.


Do a step, check it, decide whether to go again




For a chatpaste above your task


For a project foldergoes in AGENTS.md




Without a stop rule, a model will try variations of the same broken idea until you interrupt
it. With one, it comes back after two.
(04)
Stop it reaching for the wrong thing
Which tool answers which kind of question, and which ones to ignore.


Once an agent has more than about three tools, it starts guessing. It searches the web for
something sitting in your own files, or proposes a plan built on access it does not have.


Pasted into a plain chat with no tools at all, this tells the model what access you
have, so it stops suggesting things you cannot do and starts asking for what it needs.

(05)
Second Brain
A memory that outlives the conversation, so you stop re-explaining yourself every Monday.


Context is what it can see right now. It fills up, and things fall out. Memory is what
survives the conversation ending, and it is the whole difference between a tool you operate
and a colleague who already knows the background.


Once is a correction. Twice is a missing line in a file.


Correcting it in the moment costs nothing and teaches it nothing. The second time the same
thing happens, write the line down. Some tools now save your corrections for you. Go and read
what they saved, because they get it wrong sometimes.

When the data cannot leave
A model on your own machine. No graphics card, free, and it works with the wifi off.


Good enough for pulling fields out of messy text, summarising, classifying, and first drafts.
Worse than a frontier model at hard reasoning, and that is fine.


The local model filters. The cloud model finishes.


Run the local one over anything sensitive, send only what is left to the better model. That
is also the answer when someone asks whether you are allowed to use this at work.
